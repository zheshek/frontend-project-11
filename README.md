RSS Aggregator

RSS Aggregator — это веб-приложение для чтения RSS-лент.
Пользователь может добавлять RSS-источники, просматривать посты и получать обновления автоматически.

Приложение построено на Vanilla JavaScript и использует реактивное управление состоянием.

🚀 Демо

После запуска локально приложение будет доступно по адресу:
https://frontend-project-11-rss-theta.vercel.app
✨ Возможности

📡 Добавление RSS-лент по URL
✅ Валидация ссылок
📑 Отображение списка RSS-каналов
📰 Просмотр постов из добавленных лент
👁 Отметка прочитанных постов
📥 Автоматическая загрузка новых постов
⏱ Автообновление лент каждые 5 секунд
🌐 Поддержка локализации (i18next)
📱 Адаптивный интерфейс на Bootstrap

🛠 Технологии
Frontend

JavaScript (ES Modules)
